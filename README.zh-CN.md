<p align="center">

Kiwi Search 是一个浏览器扩展，把新标签页变成搜索页。支持的浏览器见[安装说明](docs/USAGE.md#安装)。

**你的浏览器，你的数据。** 所有结果都来自你自己的浏览器、你自己的登录状态和你自己填的 Key。Kiwi 不提供账号、代理或服务器，搜索结果只给你本人看。

## 功能

- **多种搜索模式**：网页、图片、视频、新闻、购物、学术，以及社交和社区平台。
- **多个来源并排检索**：搜索引擎、视频站、学术索引和各类 API 一起查，每个来源都能在扩展设置里单独开关，设置里始终是完整的列表。
- **合并，而不是堆叠**：重复的链接和转载折叠成一条，多个来源都收录的结果排在前面。
- **少看垃圾**：决策模型隐藏内容农场和跑题的页面；也可以订阅 uBlock Origin、uBlacklist、hosts 格式的屏蔽列表，不需要任何 Key。
- **带引用的 AI 概览**：用你自己的 OpenAI 兼容模型，或浏览器自带的内置模型，概览流式生成，带 `[n]` 引用，语言可选；简短的事实问题会在结果上方直接给出快答。
- **为查资料而做**：智能学术搜索会把模型给出的论文逐篇到学术索引核对；新闻可以限定最近一天、一周或一个月；购物展示各家电商的商品卡片。
- **接入你的 Agent**：本地 MCP 服务让任何支持 MCP 的 Agent 通过你的浏览器执行同一套搜索。

## 说明

Kiwi Search 只在你自己的浏览器中执行，由你本人或你自己的 Agent 主动发起；不会替你破解验证码，各来源分别排队并限速。搜索引擎的服务条款通常禁止自动化查询，这些措施不代表搜索引擎授权。请仅供个人使用，自行承担风险，并遵守当地法律及各来源的服务条款。第三方的标志和产品名称归其所有者所有。
