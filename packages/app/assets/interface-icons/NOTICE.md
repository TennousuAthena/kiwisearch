# Search navigation icons

The SVGs in this directory are unmodified Lucide source assets, fetched from the official repository on 2026-11-13 at commit `c55aab36b553a7de50a0050e7042fd7b2d64664e`. Their paths are embedded in `lib/icons.tsx`; the shared Kiwi wrapper renders them with the existing 1.75px rounded stroke and `currentColor` rather than Lucide's default 2px stroke. No remote font, CDN or package is loaded at runtime.
