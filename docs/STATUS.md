# 项目总结与现状

截至 2026-11-12。这份文档回答三个问题：做成了什么，每样东西验证到了什么程度，接下来该注意什么。设计理由和逐条的已知缺口在 [PLAN.md](PLAN.md)，实现怎么搭的在 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 一句话

Kiwi Search 是一个在用户自己的浏览器里跑的元搜索：用你自己的浏览器、登录状态和 Key，同时查多个来源，去重融合，用决策模型过滤内容农场，再用你自己的模型写出带引用的概览；同一套能力通过本地 MCP 服务提供给 Agent。没有 Kiwi 的服务器，不提供账号、Key 或代理。

## 没做的

- **输入时的搜索建议、通用的时间筛选**（P5）。学术标签里已经有“某年以来”的筛选。
- **更多平台**：微博、抖音、豆瓣、贴吧、小宇宙、GitHub、Reddit、V2EX 等。每个都需要真实页面夹具和登录状态。
- **已登录平台的全文读取**：概览目前只读搜索结果自带的摘录。
- **检索式改了重搜**：智能学术的检索式目前只读展示。
- **Semantic Scholar**：匿名额度全球共享，实测直接 429，等有 Key 再加。
- **Google 图片、Brave / SearXNG 图片**。
- **视频的过滤**：现有的“内容农场”问题是为网页写的，对视频不合适，需要另写。
- **`packages/experiments`**：只有一个空壳，README 提到的 CLI 和评测报告不在仓库里；因此根目录 `pnpm test` 会失败。

## 关键决定和原因

1. **只在用户自己的浏览器里执行，不提供账号、Key 或服务器。** 服务端直接请求搜索引擎会进反爬页面，而用户自己的浏览器本来就能正常打开；这也让合规边界清楚：每次搜索由用户或用户自己的 Agent 发起，结果只给本人看。搜索引擎的服务条款通常禁止自动化查询，这些措施不等于对方授权，README 里写明了。
2. **不自动破解验证码，不打扰用户。** 遇到验证码只在页面上提示，用户点才弹窗；工作标签页放在一个最小化的专用窗口里，不进用户正在用的窗口。
3. **决策模型是可换服务商的一层。** 专用小模型又快又便宜，是推荐；聊天模型只作兜底。TypeSafe 的 Jev 只是预设，任何实现协议的服务都能接。
4. **概览和过滤只用于文字类模式。** 图片、视频、小红书笔记、X 推文是媒体或社交卡片，不判定、不概览。知乎和小红书不抓正文（登录墙），只用它们自己的摘录。
5. **论文必须在索引里核对存在才显示。** 智能学术里模型凭记忆点名的论文，查不到就丢掉，所以不会把编出来的论文放上页面。
6. **页面上不展示搜索来源。** 只有被两个以上引擎收录的结果，才在站点名后淡淡地带几枚真品牌 logo 的小图标；除此之外，只在验证码提示里提到来源。
7. **没有改默认搜索引擎的设置覆盖。** Chrome 不允许扩展自动改，README 里是手动添加的步骤。
8. **屏蔽列表默认全关，推荐名单里没有 eallion 的合集。** 订阅是向第三方主机发请求，要用户自己打开；那个合集混着作者的个人口味（整个 baidu.com、csdn.net 都在里面），想用的人可以自己按地址订阅。
9. **被屏蔽的结果折叠而不是删除。** 第三方名单和模型都会误判，一次点击能看到被藏的，才能发现和纠正。

## 待决定

- **上架各商店。** 2026-11-12 评估过：合适的顺序是 Edge → Firefox → Chrome → Safari。Chrome 的单一用途规则要求提供网页搜索体验的新标签页扩展用 Chrome Search API，或通过 `chrome_settings_overrides.search_provider` 声明，这和现在 Kiwi 自己的搜索页冲突，是唯一可能改变产品形态的发现。还没有选路线，也没有改动清单。
- **摘要模型、默认开哪些来源、是否彻底移除 LLM 重排**：见 [PLAN.md](PLAN.md) 第 9 节。

## 接下来建议

1. 把没验证的补上：在真实、没登录的浏览器里看一次知乎、X、搜狗、哔哩哔哩的拦截和登录页，把猜的选择器换成真的；在有权限的浏览器里手测 Web of Science 和知网；在真实 Chrome 里搜一次图片，核对 Bing 图片解析器。
2. 用约 30 个查询的小评测集校准决策模型的阈值（相关度下限 0.2、隐藏 0.7、权重 0.75、意图 0.6 和 0.85 都是初值）。
3. 让根目录的 `pnpm test` 能通过：给 `packages/experiments` 的测试脚本加 `--passWithNoTests`，或者把评测的代码补回来。
4. 一个想法：把“优先显示的网站”也做成可订阅的名单（例如事实核查机构的认证名单），和屏蔽列表对称。
