# 项目总结与现状

截至 2026-11-13。这份文档回答三个问题：做成了什么，每样东西验证到了什么程度，接下来该注意什么。设计理由和逐条的已知缺口在 [PLAN.md](PLAN.md)，实现怎么搭的在 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 一句话

Kiwi Search 是一个在用户自己的浏览器里跑的元搜索：用你自己的浏览器、登录状态和 Key，同时查多个来源，去重融合，用决策模型过滤内容农场，再用你自己的模型写出带引用的概览；同一套能力通过本地 MCP 服务提供给 Agent。没有 Kiwi 的服务器，不提供账号、Key 或代理。

## 做成了什么

| 方面 | 现状 |
|---|---|
| 搜索模式 | 10 种：网页、图片、视频、新闻、购物、学术、知乎、小红书、公众号、X |
| 来源 | 34 个：23 个浏览器渲染的引擎，11 个 API 来源 |
| 融合 | URL 归一化去重；DOI、arXiv、视频、笔记各有键；论文按 DOI 或标题加年份合并；多站点转载折叠；维基百科各语言版本和简繁体按浏览器语言只留一份（中文浏览器默认开）；RRF，权重可调 |
| 过滤与排序 | 决策模型（可换服务商，聊天模型兜底）判相关度、内容农场和用户自己的规则；被隐藏的折叠、可展开 |

| AI 概览与快答 | 网页中的简短事实问题可在首条结果上方显示大字结论、小字说明和引用；复用同一次概览生成，人口等动态数据注明日期和统计口径；其他查询保留普通概览。带 `[n]` 引用；对混合平台的结果说明各平台差异；检查正文里有没有针对模型的指令；语言可设：跟随浏览器（默认）、自动（跟搜索词）、20 种语言或自己写 |
| 智能学术 | 用户自己的模型出检索式和代表论文，逐篇到 OpenAlex/Crossref 核对，查不到的丢掉；可限定只看英文文献（学术标签里选，记住选择），中文查询会改写成英文检索式 |
| 按意图补搜 | “全部”里判断要不要同时搜学术、知乎、小红书、公众号，或建议换到图片、视频、学术标签 |
| 界面 | 叶绿品牌色、分别调整的亮暗主题；K 标志已接入首页、结果页、设置页、标签 favicon 和扩展图标；Google 式的新标签页；设置页（整页打开）按用途分区、自动保存、显示每个来源上一次的状态；网站图标；每条结果带它来自的引擎的小图标（多个引擎收录的叠成一叠，只有一个引擎的画得淡） |
| MCP | `search`、`answer`、`list_sources`；多个 MCP 客户端共用一个浏览器连接 |
| 代码与测试 | 3 个有代码的包；测试 core 531 条、extension 168 条、mcp 17 条（共 716），全部通过；类型检查及构建通过（2026-11-13） |

## 关键决定和原因

1. **只在用户自己的浏览器里执行，不提供账号、Key 或服务器。** 服务端直接请求搜索引擎会进反爬页面，而用户自己的浏览器本来就能正常打开；这也让合规边界清楚：每次搜索由用户或用户自己的 Agent 发起，结果只给本人看。搜索引擎的服务条款通常禁止自动化查询，这些措施不等于对方授权，README 里写明了。
2. **不自动破解验证码，不打扰用户。** 遇到验证码只在页面上提示，用户点才弹窗；工作标签页放在一个最小化的专用窗口里，不进用户正在用的窗口。
3. **决策模型是可换服务商的一层。** 专用小模型又快又便宜，是推荐；聊天模型只作兜底。TypeSafe 的 Jev 只是预设，任何实现协议的服务都能接。
4. **概览和过滤只用于文字类模式。** 图片、视频、购物、小红书笔记、X 推文是媒体、商品或社交卡片，不判定、不概览。知乎和小红书不抓正文（登录墙），只用它们自己的摘录。
5. **论文必须在索引里核对存在才显示。** 智能学术里模型凭记忆点名的论文，查不到就丢掉，所以不会把编出来的论文放上页面。
6. **页面上不用文字展示搜索来源，只用小图标。** 每条结果在站点名后带返回它的引擎的真品牌 logo：多个引擎收录的叠成一叠、清晰；只有一个引擎的也画，但压到不透明度 0.5（2026-11-12 用户要求，原来是单个引擎的不画）。除此之外，只在验证码提示里提到来源。
7. **没有改默认搜索引擎的设置覆盖。** Chrome 不允许扩展自动改，README 里是手动添加的步骤。
8. **屏蔽列表默认全关，推荐名单里没有 eallion 的合集。** 订阅是向第三方主机发请求，要用户自己打开；那个合集混着作者的个人口味（整个 baidu.com、csdn.net 都在里面），想用的人可以自己按地址订阅。
9. **被屏蔽的结果折叠而不是删除。** 第三方名单和模型都会误判，一次点击能看到被藏的，才能发现和纠正。

## 待决定
