Kiwi Search

在你自己的浏览器里同时搜索多个来源，合并、过滤后显示，并可以生成带引用的 AI 概览。

安装扩展 打开搜索

打开搜索需要先装好扩展：搜索由扩展在你的浏览器里完成，网站只提供页面。

它做什么

  • 多种搜索模式。网页、图片、视频、新闻、购物、学术，以及社交和社区平台。
  • 多个来源并排。搜索引擎、视频站、学术索引和 API 一起查询，每个来源都能在设置里开关。
  • 合并而不是堆叠。重复的链接和转载折叠成一条，多个来源都给出的结果排在前面。
  • 更少的垃圾。决策模型隐藏内容农场和跑题的页面；也可以订阅屏蔽列表。
  • 带引用的 AI 概览。使用你自己的 OpenAI 兼容模型，或浏览器自带的模型。
  • 配合你的 Agent。本地 MCP 服务让支持 MCP 的 Agent 通过你的浏览器做同样的搜索。

数据来自你自己的浏览器

每条结果都来自你自己的浏览器、你自己的登录和你自己的 API Key。Kiwi 不提供账号、代理或服务器，结果只显示给你。详见隐私。
