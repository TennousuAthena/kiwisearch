安装

Kiwi Search 还没有上架浏览器商店，目前从源码构建后加载。

Chrome 和 Edge

  1. 需要 Node.js 24 和 pnpm 12。从 GitHub 取得源码，在仓库根目录运行 pnpm install 和 pnpm --filter @kiwi-search/extension build。
  2. 在 Chrome 打开 chrome://extensions（Edge 打开 edge://extensions），启用“开发者模式”。
  3. 点“加载已解压的扩展程序”，选择 apps/extension/.output/chrome-mv3。

Firefox

  1. 运行 pnpm --filter @kiwi-search/extension build:firefox。
  2. 打开 about:debugging#/runtime/this-firefox，点“临时载入附加组件”，选择 apps/extension/.output/firefox-mv2/manifest.json。临时载入的扩展在浏览器重启后要重新载入。

装好之后

设置页会自动打开一次，里面有“开始使用”引导。怎么打开 Kiwi、怎么设为默认搜索，见开始使用。
