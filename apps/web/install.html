安装

从 GitHub Releases 获取 Kiwi Search 安装包，按浏览器选择 ZIP 文件。浏览器商店尚未上架。

获取最新版本 所有 Release

Chrome 和 Edge

  1. 在最新 Release 的 Assets 中，Chrome、Chromium、Brave 和 Opera 选择以 chrome-mv3.zip 结尾的安装包；Edge 选择以 edge-mv3.zip 结尾的安装包。下载后解压到一个固定目录。
  2. 在 Chrome 打开 chrome://extensions（Edge 打开 edge://extensions），启用“开发者模式”。
  3. 点“加载已解压的扩展程序”，选择解压后包含 manifest.json 的目录。安装后保留这个目录。

Firefox

  1. 下载最新 Release 中以 firefox-mv2.zip 结尾的安装包并解压。
  2. 打开 about:debugging#/runtime/this-firefox，点“临时载入附加组件”，选择解压目录中的 manifest.json。当前 Firefox 包未签名，临时载入的扩展在浏览器重启后要重新载入。

更新扩展

下载新版本后，将 ZIP 解压到原安装目录，在浏览器扩展管理页点击 Kiwi Search 的“重新加载”。保留原目录和扩展，已有设置会继续使用。

从源码构建

需要 Node.js 24 和 pnpm 12。从 GitHub 取得源码，在仓库根目录运行 pnpm install，再运行 pnpm --filter @kiwi-search/extension build（Chrome）、pnpm --filter @kiwi-search/extension exec wxt build -b edge（Edge）或 pnpm --filter @kiwi-search/extension build:firefox（Firefox）。按上述步骤加载 apps/extension/.output/ 中对应的目录。

装好之后

设置页会自动打开一次，里面有“开始使用”引导。怎么打开 Kiwi、怎么设为默认搜索，见开始使用。
