Install

Get Kiwi Search from GitHub Releases and choose the ZIP for your browser. Browser store listings are not available yet.

Get the latest version All releases

Chrome and Edge

  1. In the latest release's Assets, choose the ZIP ending in chrome-mv3.zip for Chrome, Chromium, Brave or Opera, or edge-mv3.zip for Edge. Download it and extract it to a permanent folder.
  2. Open chrome://extensions in Chrome (edge://extensions in Edge) and turn on Developer mode.
  3. Click “Load unpacked” and choose the extracted folder containing manifest.json. Keep that folder after installing.

Firefox

  1. Download and extract the latest release's ZIP ending in firefox-mv2.zip.
  2. Open about:debugging#/runtime/this-firefox, click “Load Temporary Add-on” and choose manifest.json in the extracted folder. The current Firefox package is unsigned; a temporarily loaded extension has to be loaded again after the browser restarts.

Update the extension

Download the new version, extract the ZIP into the original install folder, then click Reload for Kiwi Search on the browser's extensions page. Keep the original folder and extension to continue using your settings.

Build from source

You need Node.js 24 and pnpm 12. Get the source from GitHub, run pnpm install in the repository root, then run pnpm --filter @kiwi-search/extension build (Chrome), pnpm --filter @kiwi-search/extension exec wxt build -b edge (Edge) or pnpm --filter @kiwi-search/extension build:firefox (Firefox). Load the matching folder in apps/extension/.output/ using the steps above.

After installing

The settings page opens once, with a getting-started guide. How to open Kiwi and how to make it your default search is on Get started.
