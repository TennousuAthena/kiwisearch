Install

Kiwi Search is not in a browser store yet. For now you build it from source and load it.

Chrome and Edge

  1. You need Node.js 24 and pnpm 12. Get the source from GitHub and run pnpm install and pnpm --filter @kiwi-search/extension build in the repository root.
  2. Open chrome://extensions in Chrome (edge://extensions in Edge) and turn on Developer mode.
  3. Click “Load unpacked” and choose apps/extension/.output/chrome-mv3.

Firefox

  1. Run pnpm --filter @kiwi-search/extension build:firefox.
  2. Open about:debugging#/runtime/this-firefox, click “Load Temporary Add-on” and choose apps/extension/.output/firefox-mv2/manifest.json. A temporarily loaded extension has to be loaded again after the browser restarts.

After installing

The settings page opens once, with a getting-started guide. How to open Kiwi and how to make it your default search is on Get started.
